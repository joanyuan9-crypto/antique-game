# 老古董 · 双人解谜小馆

保留两个协作解谜关卡：面值密码锁、瑞兽镇阵。新增沈砚（执册）与阿棠（解锁）两位原创矢量角色，支持双人组队、快速匹配与单人练习。

## 运行与部署

Node.js 20 或以上。

```sh
npm ci
npm start
```

打开 `http://localhost:3000/game.html`。Render 继续使用原来的 Web Service：

- Build Command：`npm ci`
- Start Command：`npm start`（原来的 `node server.js` 也兼容）
- Health Check Path：`/health`
- `PORT` 由 Render 提供；不需要新增密钥、数据库或外部素材服务。

本版本仍为内存房间，适合单个 Render 实例。部署/重启会结束当前房间；横向扩容前须增加共享状态和 Socket.IO adapter。此版本更新了联机消息协议，部署后旧页面需要刷新。原有本机 `level1Passed` 通关标记继续识别。

## 玩法与改动

- 两关都可直接体验，第一关保留已通关徽标。
- 入门：8 次机会，3 条共享提示，显示正确位置。
- 雅集：6 次机会，2 条共享提示，显示选对数量和放对位置数。
- 问鼎：4 次机会，1 条共享提示，优先使用关系线索。
- 每局生成不同谜题；以六选四的全部 360 种排列校验唯一解。每条规则和提示均从本局实际答案产生，不再使用可能互相矛盾的固定提示。
- 点选位置替换；已选古物交换位置；撤销、单独移除、清空、试答回填。
- 错误后保留排列；重复试答不扣机会；用尽次数后可查看答案与历史，无自动重置。
- 双人房由服务端统一出题、验证和广播。匹配按关卡与难度分组；双方共享提示次数；游戏进行中重开须伙伴确认。
- 断线暂停操作并保留座位 60 秒；同一标签页刷新或重连可恢复角色、排列、历史和聊天。
- 数字 1–6 选古物，方向键选位置，退格移除，Enter 验证。聊天中 Enter 发送，Shift+Enter 换行。
- 手机页面可用“翻阅另一半线索 / 与伙伴传音”和“回到机关”快速跳转。

## 文件

- `game.html`：游戏页面，仍由原来的 `/game.html` 路径访问。
- `public/app.js`：交互、练习与联机控制。
- `public/engine.js`：可在浏览器和服务端复用的出题、验证与回合规则。
- `public/styles.css`、`public/assets/`：样式和本地素材。
- `server.js`：Express + Socket.IO 服务；只公开游戏及 public 资源。
- `test/`：规则与双人联机回归测试。

## 验证

```sh
npm test
```

测试覆盖六个关卡/难度组合的 1,500 道确定种子谜题、提示正确性、操作撤销、重复试答、输赢状态、任意角色建房、玩家权限、双人重开、匹配分队、重连与超时、静态资源边界。

浏览器实测：两关完整通关、练习角色切换、提示、390px 手机与 1280px 桌面布局；两个浏览器标签页以不同角色建房、加入、分享资料、摆放与同步通关。
